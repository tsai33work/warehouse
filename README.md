# 松青營造｜倉庫進出登記網頁

這是一個手機用的登記網頁，放在 GitHub Pages 上。資料即時寫入 Google 試算表，由 Apps Script v3 處理。

- **登記**：依序點選人員、進／出、貨品大項、細項、名稱（規格）、數量，再按「加入清單」。可以一次加入多個品項，最後一起送出。
- **進出歷程**：可以依期間、進出、人員、大項篩選，也能用關鍵字搜尋。
- **庫存**：顯示即時帳面庫存。可以只看需要注意的品項，例如帳面為負、需補貨或期初未盤點。

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本體，不需要修改 |
| `config.js` | 這裡貼上 Apps Script 網址 |

## 設定步驟

### A. Google 試算表端（Apps Script）
1. 打開試算表，進入「擴充功能 → Apps Script」，用 `倉庫進出登記系統_v3.gs` 的內容整份取代原本的程式碼，然後存檔。
2. 從函式選單選 `setupWebApi`，按「▷ 執行」。執行後，「設定」分頁的 H2 會出現 6 位數的**網頁通行碼**。
3. 點右上角「部署 → 新增部署作業」，齒輪選「網頁應用程式」，設定如下：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，並在授權視窗按允許。複製畫面上的**網頁應用程式網址**，結尾是 `/exec`。

### B. GitHub 端
1. 登入 GitHub，按右上「＋ → New repository」，名稱例如 `warehouse`，可見性選 **Public**，然後按 Create。免費帳號的 GitHub Pages 需要公開的 repo，但資料受通行碼保護，網頁本身沒有存資料。
2. 在 repo 頁面點「Add file → Upload files」，把 `index.html`、`config.js`、`README.md` 拖進去，按「Commit changes」。
3. 點 `config.js` 右上的鉛筆圖示編輯，把步驟 A-4 的網址貼進 `API_URL: ''` 的引號中，再按「Commit changes」。
4. 進入「Settings → Pages」，在 Source 選「Deploy from a branch」，Branch 選 `main` 和 `/ (root)`，然後按 Save。
5. 等 1～2 分鐘，網址會出現在同一頁，格式是 `https://你的帳號.github.io/warehouse/`。

### C. 現場人員
- 用手機打開上面的網址，第一次使用時輸入通行碼。
- 在 iPhone 的 Safari 按「分享 → 加入主畫面」，或在 Android 的 Chrome 按「⋮ → 加到主畫面」，之後就能像 App 一樣直接開啟。

## 日後維護
- **新增品項、人員或分類**：直接在試算表修改，網頁按右上「↻」或重新打開就會更新，不必重新部署。
- **修改了 Apps Script 程式碼**：要點「部署 → 管理部署作業 → ✏️ → 版本：新版本 → 部署」，網址不會變。
- **更換通行碼**：修改「設定」分頁的 H2，所有人下次開網頁時要重新輸入。
- **登記錯誤**：在「進出歷程」把該列「計入庫存」改成「否（作廢）」，再重新登記一次。
